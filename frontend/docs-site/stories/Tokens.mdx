# Design Tokens

These tokens are generated from `@monorepo/design-tokens` and exposed as CSS custom properties on `:root`. They are the only colors, spacings, radii, and typographic values that components are allowed to use.

The `storybook-design-token` addon parses the loaded CSS variables and renders the panels below. You can also open the **Design tokens** tool in the Storybook toolbar to browse them interactively.
