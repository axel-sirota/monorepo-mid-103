# Churn-model experiment log

Append-only journal of churn-model training runs. The `/log-experiment` skill
appends one entry per run to this file. Most-recent-at-bottom (read top-to-bottom
as a story of what was tried and what was learned).

Each entry has: date, experiment name, MLflow run_id (linked), seed, params,
metrics, hypothesis, outcome, and the path to the joblib artifact. The skill
also dispatches a verifier sub-subagent that confirms the artifact loaded.

If MLflow is unreachable when an experiment runs, the entry is still appended
but flagged "MLflow unreachable — partial entry" in the Outcome section.
