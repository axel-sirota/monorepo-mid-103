# PM persona — pre-class setup

## Required

- Claude Code CLI
- A text editor you like (PRDs are Markdown)
- `git` 2.30+ (the Lab 3 hook runs `git diff --cached` from a shell)
- Python 3 (used by the Lab 3 install-hook.py installer — ships with macOS;
  `apt-get install python3` on Linux)

## Strongly recommended

- Jira API token if your team uses Jira (and you want `/pm-report` to pull live ticket status)
- A GitHub personal access token for issue links

## Pre-class warm-up

```bash
ls prds/
# read 0001-churn-notification.md and 0002-export-user-data.md
# 0002 is deliberately incomplete — that's your 102 lab subject
```

No Docker needed for PM-only work.
